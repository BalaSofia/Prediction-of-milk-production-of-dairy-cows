# Prediction of milk production of dairy cows
## Project I7
## Team: Sofia Bala, Aleksandra Semtsova

Dataset 1 (SIZE  23.2 MB): Training dataset containing historical cow calvings from 2021 to 2024 with herd metrics, previous lactation records, genetic values and 305 - day cumulative yield targets.
Dataset 2 (SIZE 5.12 MB): Test dataset containing calvings from 2025 with identical features for evaluating model performance under time-based shift conditions. 
Goal 1: Predict a dairy cow’s total 305-day milk yield (target_milk_305_kg) at calving time using historical herd data, cow demography, previous lactation metrics, and genetic evaluation indices. 
Goal 2: Investigate which factors have the greatest influence on dairy cow productivity. 
Goal 3: Identify the regression model that provides the most accurate predictions of dairy cow milk production.
